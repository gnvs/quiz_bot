# quiz_bot

Телеграм-бот на Python в формате квиза.

## Описание

Бот задает 10 вопросов по Python, проверяет знания и сохраняет результаты. 
После прохождения квиза вы можете увидеть свой прогресс и сравнить результаты с другими игроками.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом, приветственное сообщение |
| `/quiz` | Начать новый квиз |
| `/progress` | Показать текущий прогресс и последний результат |
| `/top` | Показать топ-10 игроков по результатам |
| `/help` | Показать справку по использованию |

Также доступны кнопки в интерфейсе для удобства:
- Начать квиз
- Мой прогресс
- Топ игроков
- Помощь

## Функционал

1. **Асинхронная работа** - бот работает на asyncio и aiogram
2. **Сохранение прогресса** - можно прервать и продолжить с того же места
3. **База данных SQLite** - сохраняются результаты всех игроков
4. **Таблица лидеров** - рейтинг лучших результатов
5. **Подробные ответы** - после каждого вопроса показывается объяснение
6. **Статистика** - отслеживание прогресса пользователя

## Структура базы данных

### Таблица `quiz_state`
- `user_id` - ID пользователя Telegram
- `question_index` - текущий номер вопроса
- `username` - имя пользователя
- `first_name` - имя в Telegram

### Таблица `quiz_results`
- `id` - уникальный идентификатор
- `user_id` - ID пользователя
- `username` - имя пользователя
- `score` - количество правильных ответов
- `total_questions` - всего вопросов
- `percentage` - процент правильных ответов
- `date` - дата прохождения
